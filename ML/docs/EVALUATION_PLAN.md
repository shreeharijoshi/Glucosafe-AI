# Evaluation Plan

Use precision, recall/sensitivity, F1, PR-AUC or average precision, ROC-AUC as a supplementary metric, confusion matrices, specificity, and calibration assessment where feasible. Accuracy alone is inadequate for an imbalanced hypoglycemia target.

Report pooled results and per-participant results. Confidence intervals or participant-level variability should be considered because participant counts are limited.

Model A and Model B must use the same held-out participants, target definition, eligible timestamps, and evaluation policy. If Model B requires valid current-meal carbohydrates, define a common evaluation population or a predeclared missing-input strategy so the comparison is not biased by different test populations.

Offline metrics do not establish clinical usefulness or safety.
